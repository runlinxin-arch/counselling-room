# 《心理咨询》

叙事驱动 + 选项对话的**康复心理学科普**游戏。玩家扮演康复医院心理门诊的咨询师，
接待因伤病或残障而来访的人。

**交付物就是一个文件**：[`心理咨询.html`](心理咨询.html)，双击即玩。
没有后端、没有构建工具链、没有外部依赖、不联网、不装任何东西。

> **本作品为康复心理学课程作业。**
> 故事、人物、机构均为虚构，与任何真实的人、单位、事件无关。
> 本作品不构成任何医疗建议，不能替代真实心理咨询。
> 如你正经历心理困扰，请联系专业机构或拨打 **12356**（全国心理援助热线）。
> 存在立即的危险，请拨打 **120**。

这条线讲的是：**一个把「等我能走了」当成人生的前提、因而什么也不做的人，
怎么重新找到此刻就能做的事。** 重点不是"接受瘫痪"，是**目标调整**。

玩家做的事：读对话 → 做选择 → 看房间里用箭头标出来的物件用处。
全程只用鼠标，键盘 `1` `2` `3` 也能选。

### 游戏里有的几件事

- **督导笔记**——每次选完，一张纸从右边滑进来，字是一个一个"写"出来的。
  它讲的是刚才那一步为什么好、为什么不好。**不扣分、不评判玩家。**
- **情绪日记**——来访者写的家庭作业，玩家逐条点开，自己从中找出认知歪曲。
- **危机筛查**——设计成"可以不问"。选了不问**不惩罚、不扣分**，但会留痕，终章提示。
- **危机关怀分支**——写死在数据里，不经过任何模型判断。

## 跑起来

```powershell
# 玩
双击 心理咨询.html

# 改完源码重新生成产物
node build.mjs

# 全部检查（含开真实 Chrome 走一遍）
node tests/run-all.mjs
```

`node tests/run-all.mjs` 会依次跑：

| 脚本 | 查什么 |
| --- | --- |
| `render-sprites.mjs` | 像素画行宽 / 调色板 / 摆位，并出图供人眼验收 |
| `check-game.mjs` | 结构 · 美术 · **红线** · 剧情 · **真跑一遍渲染** |
| `smoke-browser.mjs` | 开 Chrome，确认页面真的启动（没有未捕获错误） |
| `check-acceptance.mjs` | 存档续玩 · 1366×768 上不溢出 |
| `walkthrough.mjs` | 走完整条故事线，11 张截图 + 房间箭头标注与危机分支断言 |

**红线是自动核对的**，包括：热线出现次数 ≥3、9 个禁用词、剧情数字白名单
（每个数字都要在教材里有出处，没有的绝不编）、以及"18 个选项逐个都能走到终章"。

## 代码结构

源码按职责拆开写，`build.mjs` 合并成**一个** HTML。
单文件是*交付*要求，不是*开发*要求——在 12 万字符的 HTML 里改一句台词是把整份文档丢给编辑器。

```
心理咨询.html        ← 交付物（由 build.mjs 生成，别手改）
build.mjs            ← 唯一的合并点

src/
  shell.html         页面骨架，含 <!--INJECT:...--> 占位符
  styles.css         全部样式（设计令牌在最上面的 :root）
  sprites.json       15 个像素物件（从方案 B 小样自动抽出，别手改）
  sprites.js         立绘 + 场景时段变体 + 补充调色板
  story.js           内容数据：当前这一条线（现为脊髓损伤占位）全脚本
  engine.js          状态机 + 存档 + 场景渲染
  ui.js              界面：标题页 / 选线 / 对话 / 纸 / 日记 / 逐字写出

tools/
  extract-sprites.mjs   从方案 B 抽出像素地图 → src/sprites.json
  fetch-repos.mjs        下载第三方源码资料库到 resources/

docs/
  design/2026-09-27-…设计文档.md    页面流程 / 数据格式 / 存档结构 / 验收标准
  plans/2026-09-27-…实施计划.md     工程结构与实施顺序
  story/故事线0-许予安.md          新线规格（人物 / 前史 / 专业依据 / 红线自查）
  story/故事线1-脊髓损伤.md        台词正本（现为占位线）
  mockups/方案B-内联SVG.html       咨询室像素美术原始小样（美术以它为准）
  mockups/shots/*.png              立绘 / 房间 / 游戏内截图
  项目存档-Notion.md               决策记录 · 待办 · 踩坑记录 · 进度速览
```

### 换一条故事线

引擎只认识 `say / choice / diary / card / result` 五种节点，**不认识任何诊断**。
换线是纯数据工作：写一份同样结构的数据放进 `XLZX.stories`，再把
`XLZX.storySlots` 里那一条指向它。不用动引擎。

随身物件（轮椅 / 双拐 / 包）也由故事数据的 `clientArt` 决定，不写死在引擎里——
正是为了换线时不会出现「别人的轮椅」。

## 技术上守住的几条

- **单文件交付**：无外部引用（`src`/`href` 全为空）、不用 `fetch` / XHR / ES module，
  所以 `file://` 直接双击就能跑
- **像素画是文字**：画面用字符地图写在代码里，SVG `<rect>` 渲染。
  改画面像打字，不用开画图软件；没有图片文件，素材永远不会丢
- **存档在本地**：`localStorage`，只存在这台电脑的浏览器里，不上传
- **无障碍**：键盘 Tab 能走到每个按钮、`1`/`2`/`3` 能选、尊重
  `prefers-reduced-motion`（开了就关掉逐字写出和所有动效）

## 专业依据

内容以《Handbook of Rehabilitation Psychology》第三版（APA, 2019）为准，
用到的章节与数据全部列在 [`docs/项目存档-Notion.md`](docs/项目存档-Notion.md) 第七节。

**教材全文不入版本控制**（第三方出版物，见 `.gitignore`）；
精读摘要见 `docs/reference/第7章第9章阅读摘要.md`。

写作与开发全程遵守的红线（不下诊断、不给药物建议、不评判来访者家人、
避免"恢复正常"叙事、person-first 用语、数字必须有出处……）逐条列在同一份存档的第八节。
