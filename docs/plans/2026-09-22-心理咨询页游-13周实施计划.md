# 《心理咨询》网页游戏 · 13 周实施计划

> **For agentic workers:** 每周任务按「一步一勾」执行，勾选后立即 commit。步骤使用 `- [ ]` 复选框语法跟踪。

**Goal:** 在 13 周内交付一款可在浏览器直接打开的叙事驱动 + AI 对话心理咨询模拟游戏，达到「科普心理咨询与心理障碍」的课程作业水平，并保留后续扩展为完整版（Steam）的架构。

**Architecture:** Phaser 4 负责场景渲染与交互（咨询室 / 心境小屋两个可切换场景）；叙事主线由 ink 剧本文件驱动，通过 inkjs 运行时嵌入 Phaser；仅 2~3 个环节开放自由文本输入，经 Serverless 中转调用大模型，输出受「规则前置拦截 → 安全提示词 → 输出复核」三层护栏约束。游戏状态（章节进度、已解锁物品、已看记忆片段）持久化到 localStorage。

**Tech Stack:** Phaser 4 · TypeScript · Vite · ink/inkjs · Zod · Vitest · Playwright · Vercel Serverless（或 Cloudflare Workers）· AI SDK / openai-node

## Global Constraints

以下为项目级硬约束，**每一个任务的要求都隐含包含本节**。

- **引擎版本**：Phaser `^4.2.0`（**不是 Phaser 3**）。v4 的统一 Filter 系统与 `setLighting(true)` 是本项目「房间逐章变亮」机制的技术基础。
- **语言**：TypeScript `^5.6`，`tsconfig.json` 必须开启 `"strict": true`。
- **构建**：Vite `^7`，开发命令 `npm run dev`，产物命令 `npm run build`。
- **Node 版本**：`>=20`。
- **基准分辨率**：`1280 × 720`，缩放模式 `Phaser.Scale.FIT`，`autoCenter: Phaser.Scale.CENTER_BOTH`。
- **术语规范**：报告与游戏内文案统一使用「抑郁症 / 抑郁障碍」，不使用「抑郁病」「精神病」等口语化或污名化表述。
- **API Key 约束**：任何前端代码（`src/**`）中**不得出现**大模型 API Key 字面量或环境变量引用。Key 只存在于服务端函数运行时环境。
- **安全护栏约束**：自伤/自杀信号必须在**代码层前置拦截**，命中后不调用大模型，直接渲染剧本写死的关怀分支 + 求助资源卡。
- **求助资源**：全国统一心理援助热线 `12356`（国家卫健委统一号码），另附北京 `010-82951332`。资源文案至少出现 3 处：游戏主菜单「关于」、终章片尾、自由输入环节常驻入口。
- **免责声明原文**：`本作品为康复心理学课程作业，不构成任何医疗建议，不能替代真实心理咨询。如你正经历心理困扰，请联系专业机构或拨打 12356。`
- **素材登记**：每一份美术/音频素材（含 AI 生成）必须在 `docs/assets-provenance.md` 登记：文件名、来源（AI 模型 + prompt 摘要 / 素材站链接）、许可、日期。
- **提交规范**：Conventional Commits（`feat:` `fix:` `docs:` `chore:` `test:` `art:` `content:`）。每个任务结束时必须 commit 一次；每周结束打一个 tag `week-01` … `week-13`。
- **存档兼容**：`localStorage` 键名固定为 `xinli.save.v1`；存档结构变更必须递增版本号并提供迁移函数。
- **AI 边界（写入 system prompt 且由输出层复核）**：AI 只做共情回应与开放式提问；**永远不**主动给诊断、不给药物建议、不评判玩家的家人。

```ts
import Phaser from 'phaser';
import { GAME_WIDTH, GAME_HEIGHT, DISCLAIMER, HOTLINE_NATIONAL } from '../config';

export class TitleScene extends Phaser.Scene {
  constructor() {
    super('TitleScene');
  }

  create(): void {
    this.add.text(GAME_WIDTH / 2, 200, '心理咨询', { fontSize: '56px', color: '#e8e6e3' }).setOrigin(0.5);
    this.add
      .text(GAME_WIDTH / 2, 300, '一个关于理解自己的故事', { fontSize: '20px', color: '#9a9a9a' })
      .setOrigin(0.5);

    const start = this.add
      .text(GAME_WIDTH / 2, 420, '开始', { fontSize: '28px', color: '#7fb3d5' })
      .setOrigin(0.5)
      .setInteractive({ useHandCursor: true });
    start.on('pointerdown', () => this.scene.start('TherapyRoomScene'));

    this.add
      .text(GAME_WIDTH / 2, 660, `${DISCLAIMER}\n心理援助热线：${HOTLINE_NATIONAL}`, {
        fontSize: '14px',
        color: '#6b6b6b',
        align: 'center',
        wordWrap: { width: 900 },
      })
      .setOrigin(0.5);
  }
}
```

```ts
import { Story } from 'inkjs';
import type { Choice, DialogueLine, Speaker, StoryFlags } from './types';

const VALID_SPEAKERS: Speaker[] = ['therapist', 'client', 'narration', 'info'];

function normalizeSpeaker(raw: string | undefined): Speaker {
  if (raw && (VALID_SPEAKERS as string[]).includes(raw)) return raw as Speaker;
  return 'narration';
}

export class InkRunner {
  private story: Story;

  constructor(compiledJson: object, initialFlags?: StoryFlags) {
    this.story = new Story(JSON.stringify(compiledJson));
    if (initialFlags) {
      for (const [k, v] of Object.entries(initialFlags)) {
        this.story.variablesState[k] = v;
      }
    }
  }

  continue(): DialogueLine | null {
    if (!this.story.canContinue) return null;
    const text = this.story.Continue() ?? '';
    const tags = this.story.currentTags ?? [];
    const speakerTag = tags.find((t) => t.trim().startsWith('speaker:'));
    const speaker = normalizeSpeaker(speakerTag?.split(':')[1]?.trim());
    return { speaker, text: text.trim() };
  }

  getChoices(): Choice[] {
    return this.story.currentChoices.map((c, i) => ({
      index: i,
      text: c.text.trim(),
      enabled: true,
    }));
  }

  choose(index: number): void {
    this.story.ChooseChoiceIndex(index);
  }

  getFlags(): StoryFlags {
    const flags: StoryFlags = {};
    const state = this.story.variablesState as unknown as {
      _globalVariables?: Record<string, unknown>;
    };
    if (state._globalVariables) {
      for (const [k, v] of Object.entries(state._globalVariables)) {
        if (typeof v === 'boolean' || typeof v === 'number' || typeof v === 'string') flags[k] = v;
      }
    }
    return flags;
  }

  isEnded(): boolean {
    return !this.story.canContinue && this.story.currentChoices.length === 0;
  }
}
```

```ts
import Phaser from 'phaser';
import { THEME } from './theme';
import type { DialogueLine } from '../dialogue/types';

export class DialogueBox {
  private scene: Phaser.Scene;
  private panel: Phaser.GameObjects.Rectangle;
  private nameText: Phaser.GameObjects.Text;
  private bodyText: Phaser.GameObjects.Text;
  private fullText = '';
  private shown = 0;
  private timer?: Phaser.Time.TimerEvent;
  private onDone?: () => void;

  constructor(scene: Phaser.Scene, x: number, y: number, width: number) {
    this.scene = scene;
    const height = 180;
    this.panel = scene.add
      .rectangle(x, y, width, height, THEME.color.panel, 0.94)
      .setOrigin(0, 0)
      .setStrokeStyle(2, THEME.color.panelBorder);
    this.nameText = scene.add.text(x + 24, y + 14, '', {
      fontFamily: THEME.fontFamily,
      fontSize: `${THEME.fontSize.name}px`,
      color: THEME.color.therapist,
    });
    this.bodyText = scene.add.text(x + 24, y + 48, '', {
      fontFamily: THEME.fontFamily,
      fontSize: `${THEME.fontSize.body}px`,
      color: THEME.color.text,
      lineSpacing: 8,
      wordWrap: { width: width - 48 },
    });
    scene.input.on('pointerdown', () => this.skip());
  }

  show(line: DialogueLine, onDone?: () => void): void {
    this.onDone = onDone;
    this.fullText = line.text;
    this.shown = 0;
    this.bodyText.setText('');
    this.nameText.setText(THEME.speakerLabel[line.speaker] ?? '');
    this.nameText.setColor(line.speaker === 'client' ? THEME.color.client : THEME.color.therapist);
    this.timer?.remove();
    this.timer = this.scene.time.addEvent({
      delay: THEME.typeSpeedMs,
      loop: true,
      callback: () => {
        this.shown += 1;
        this.bodyText.setText(this.fullText.slice(0, this.shown));
        if (this.shown >= this.fullText.length) this.finish();
      },
    });
  }

  skip(): void {
    if (this.isTyping()) this.finish();
  }

  isTyping(): boolean {
    return this.shown < this.fullText.length;
  }

  hide(): void {
    this.panel.setVisible(false);
    this.nameText.setVisible(false);
    this.bodyText.setVisible(false);
  }

  private finish(): void {
    this.timer?.remove();
    this.timer = undefined;
    this.shown = this.fullText.length;
    this.bodyText.setText(this.fullText);
    const cb = this.onDone;
    this.onDone = undefined;
    cb?.();
  }
}
```

```ts
import { ChoiceList } from '../ui/ChoiceList';

    this.box = new DialogueBox(this, 80, GAME_HEIGHT - 220, GAME_WIDTH - 160);
    this.choices = new ChoiceList(this, 120, 120, 800, (i) => {
      this.runner.choose(i);
      this.step();

      return;
    }
```

```ts
export type LightLevel = 0 | 1 | 2 | 3;

export interface LightPreset {
  /** 环境光亮度 0~1，越大越亮 */
  ambient: number;
  /** 糊窗灰尘层不透明度 0~1 */
  dustAlpha: number;
  /** 暖色偏移 0~1，越大越暖 */
  warm: number;
}

export const LIGHT_PRESETS: Record<LightLevel, LightPreset> = {
  0: { ambient: 0.18, dustAlpha: 0.85, warm: 0.0 },
  1: { ambient: 0.36, dustAlpha: 0.6, warm: 0.15 },
  2: { ambient: 0.58, dustAlpha: 0.3, warm: 0.35 },
  3: { ambient: 0.82, dustAlpha: 0.0, warm: 0.55 },
};

export function levelForChapter(chapter: number): LightLevel {
  if (chapter <= 0) return 0;
  if (chapter === 1) return 1;
  if (chapter <= 3) return 2;
  return 3;
}
```

```ts
export const config = { runtime: 'edge' };

const SYSTEM_PROMPT = `你是一位认知行为取向的心理咨询师，人本主义为底色。
规则（不可违反）：
1. 只做共情回应与开放式提问。每次回复不超过 120 字。
2. 永远不主动给出诊断、不给出药物建议、不评判来访者的家人。
3. 不说「你应该」「你必须」，多用「听起来……」「能多说说……吗」。
4. 如果来访者提到自伤或自杀，立即停止常规回应，表达关心并建议联系专业机构或拨打 12356。
5. 你是在一款科普性质的课程作品里，不是真实咨询。`;

export default async function handler(req: Request): Promise<Response> {
  if (req.method !== 'POST') {
    return new Response(JSON.stringify({ error: 'Method Not Allowed' }), { status: 405 });
  }

  let body: { sessionId?: string; messages?: { role: string; content: string }[] };
  try {
    body = await req.json();
  } catch {
    return new Response(JSON.stringify({ error: 'Invalid JSON' }), { status: 400 });
  }
  if (!Array.isArray(body.messages) || body.messages.length === 0) {
    return new Response(JSON.stringify({ error: 'messages required' }), { status: 400 });
  }

  const upstream = await fetch(`${process.env.LLM_BASE_URL}/chat/completions`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${process.env.LLM_API_KEY}`,
    },
    body: JSON.stringify({
      model: process.env.LLM_MODEL,
      stream: true,
      temperature: 0.7,
      max_tokens: 300,
      messages: [{ role: 'system', content: SYSTEM_PROMPT }, ...body.messages.slice(-8)],
    }),
  });

  if (!upstream.ok || !upstream.body) {
    return new Response(JSON.stringify({ error: `Upstream ${upstream.status}` }), { status: 502 });
  }

  const stream = new ReadableStream({
    async start(controller) {
      const reader = upstream.body!.getReader();
      const decoder = new TextDecoder();
      const encoder = new TextEncoder();
      let buffer = '';
      while (true) {
        const { done, value } = await reader.read();
        if (done) break;
        buffer += decoder.decode(value, { stream: true });
        const lines = buffer.split('\n');
        buffer = lines.pop() ?? '';
        for (const line of lines) {
          if (!line.startsWith('data: ')) continue;
          const payload = line.slice(6).trim();
          if (payload === '[DONE]') continue;
          try {
            const delta = JSON.parse(payload).choices?.[0]?.delta?.content;
            if (delta) controller.enqueue(encoder.encode(`data: ${JSON.stringify({ delta })}\n\n`));
          } catch {
            /* 忽略不完整分片 */
          }
        }
      }
      controller.enqueue(encoder.encode('data: [DONE]\n\n'));
      controller.close();
    },
  });

  return new Response(stream, {
    headers: { 'Content-Type': 'text/event-stream; charset=utf-8', 'Cache-Control': 'no-cache' },
  });
}
```

```ts
export interface ChatMessage {
  role: 'user' | 'assistant';
  content: string;
}

export async function streamChat(
  messages: ChatMessage[],
  onDelta: (t: string) => void,
  signal?: AbortSignal,
): Promise<void> {
  const res = await fetch('/api/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ sessionId: crypto.randomUUID(), messages }),
    signal,
  });
  if (!res.ok || !res.body) throw new Error(`chat failed: ${res.status}`);

  const reader = res.body.getReader();
  const decoder = new TextDecoder();
  let buffer = '';
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true });
    const lines = buffer.split('\n');
    buffer = lines.pop() ?? '';
    for (const line of lines) {
      if (!line.startsWith('data: ')) continue;
      const payload = line.slice(6).trim();
      if (payload === '[DONE]') return;
      try {
        const delta = JSON.parse(payload).delta;
        if (typeof delta === 'string') onDelta(delta);
      } catch {
        /* 忽略 */
      }
    }
  }
}
```

```ts
import { CRISIS_PATTERNS, ELEVATED_PATTERNS } from './crisisLexicon';

export type RiskLevel = 'none' | 'elevated' | 'crisis';

export interface RiskResult {
  level: RiskLevel;
  matched: string[];
}

/** 归一化：去除空白与常见分隔符，降低「我 想 自 杀」式绕过 */
export function normalize(input: string): string {
  return input.replace(/[\s\u3000·.,，。、~～\-_*]/g, '');
}

export function assessRisk(input: string): RiskResult {
  const text = normalize(input);
  const crisis = CRISIS_PATTERNS.filter((re) => re.test(text));
  if (crisis.length > 0) return { level: 'crisis', matched: crisis.map((r) => r.source) };

  const elevated = ELEVATED_PATTERNS.filter((re) => re.test(text));
  if (elevated.length > 0) return { level: 'elevated', matched: elevated.map((r) => r.source) };

  return { level: 'none', matched: [] };
}
```

```ts
export type RejectReason = 'diagnosis' | 'medication' | 'blame_family';

const RULES: { reason: RejectReason; re: RegExp }[] = [
  { reason: 'diagnosis', re: /(你|您)(这|那就)?是.{0,6}(抑郁症|焦虑症|双相|精神病|障碍)/ },
  { reason: 'diagnosis', re: /诊断为|确诊/ },
  { reason: 'medication', re: /(吃|服用|试试|用).{0,8}(药|舍曲林|氟西汀|帕罗西汀|安定|抗抑郁)/ },
  { reason: 'medication', re: /(加|减|停)(药|量)/ },
  { reason: 'blame_family', re: /(你|您)(父母|妈|爸|家人).{0,10}(自私|不爱|糟糕|有毒|毁了)/ },
];

export function reviewOutput(text: string): { ok: boolean; reason?: RejectReason } {
  for (const r of RULES) {
    if (r.re.test(text)) return { ok: false, reason: r.reason };
  }
  return { ok: true };
}
```

```ts
import { assessRisk } from '../ai/safety/prefilter';
import { reviewOutput } from '../ai/safety/postfilter';
import { streamChat, type ChatMessage } from '../ai/client';
import { CrisisCard } from '../ui/CrisisCard';

private async handleFreeInput(userText: string): Promise<void> {
  const risk = assessRisk(userText);
  if (risk.level === 'crisis') {
    new CrisisCard(this).show(() => this.step());
    return;
  }

  let buffer = '';
  this.box.show({ speaker: 'therapist', text: '……' });
  try {
    await streamChat([{ role: 'user', content: userText }] as ChatMessage[], (d) => {
      buffer += d;
      this.box.show({ speaker: 'therapist', text: buffer });
    });
  } catch {
    this.box.show({ speaker: 'therapist', text: '（网络好像出了点问题。我们稍后再聊这个。）' });
    return;
  }

  if (!reviewOutput(buffer).ok) {
    this.box.show({
      speaker: 'therapist',
      text: '听起来这让你很难受。能多说说，是什么让你有这样的感觉吗？',
    });
  }
  if (risk.level === 'elevated') new CrisisCard(this).show(() => this.step());
  else this.step();
}
```

```ts
export interface DiaryEntry {

  situation: string;

export class Diary {
  private entries: DiaryEntry[] = [];

  add(e: DiaryEntry): void {
    if (!Number.isInteger(e.emotion) || e.emotion < 1 || e.emotion > 10) {
      throw new Error('emotion must be an integer 1..10');
    }
    this.entries.push({ ...e });

  all(): DiaryEntry[] {
    return [...this.entries];
  }
  averageEmotion(): number {
    if (this.entries.length === 0) return 0;
    return this.entries.reduce((s, e) => s + e.emotion, 0) / this.entries.length;
  }
}
```

```ts
import Phaser from 'phaser';

export class AudioSystem {
  private current?: Phaser.Sound.BaseSound;

  constructor(private scene: Phaser.Scene) {}

  play(key: string, volume = 0.5): void {
    if (this.current?.key === key) return;
    const next = this.scene.sound.add(key, { loop: true, volume: 0 });
    next.play();
    this.scene.tweens.add({ targets: next, volume, duration: 1500 });
    if (this.current) {
      const old = this.current;
      this.scene.tweens.add({
        targets: old,
        volume: 0,
        duration: 1500,
        onComplete: () => {
          old.stop();
          old.destroy();
        },
      });
    }
    this.current = next;
  }
}
```
