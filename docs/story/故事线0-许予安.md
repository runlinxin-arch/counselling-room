## 一、这条线一句话讲什么

> **一个认为「被照顾＝被知道自己很惨」的人，怎么接受有人愿意照顾他。**

主线是**伤残适应**，不是「治愈霸凌创伤」。霸凌是前史、是病因，不是这一次咨询要解决的问题。

**核心洞察（写作时别丢）：** 隐瞒霸凌和拒绝照顾是同一件事的两面——**都不能让别人看见我弱**。

## 二、人物（均为虚构）

**来访者 · 许予安**，14 岁，男，初二
- 车祸致全身多处骨折。康复期遗留**下肢功能障碍**：右腿小腿至膝佩戴矫形支具，需长期使用双拐，可短距离行走
- 伤后约 5 个月，已出院回家
- **障碍状态全程不变。** 身体不会变好，变的是他和身体、和别人的关系
- 是他自己开口说要做心理康复的。父母以为这是好事，他自己说不清为什么

**李秀兰（李阿姨）**，52 岁
- 在这家做保洁六年，许予安小时候她就在
- 像妈妈一样照顾他。车祸后接送、擦身、做饭都是她
- 来自外地，自己的孩子留在老家；她有疲惫、有生活，**不是圣人**
- 许予安对她有**身份上的隔阂**：「她不是我妈」。他从没对她说过被霸凌

**父亲 / 母亲**
- 都在工作，都很爱他，但长期缺席
- 车祸后才发现他身上有许多旧伤。他们的反应是自责 + 补偿性地加倍保护
- **不写成反派**

**你（玩家）**：这家康复医院心理门诊的咨询师。

**关键设计：** 他是**自己愿意来的**，但什么都不说。这跟「被家长押着来」是两种完全不同的阻抗——他不是不愿意谈，他是不知道该谈什么，也不相信谈有用。

## 三、事情经过（前史）

按时间顺序。台词里**逐段揭示，不要一次倒完**：

1. 许予安在班里长期被霸凌（时长与形式留在台词里慢慢说）
2. 他从未告诉任何人。父母太忙，李阿姨是「外人」，他说不出口
3. 某天放学后精神恍惚走上马路，被车撞
4. 多处骨折，住院、手术、康复
5. 父母在护理时发现他身上有许多旧伤 → 反复追问 → 霸凌真相暴露
6. 伤情稳定后，他提出要做心理康复
7. **故事从这里开始：第一次心理咨询**

## 四、主题与专业依据

依据《Handbook of Rehabilitation Psychology》第三版（APA, 2019）：

| 章节 | 用在哪 |
|---|---|
| **第 5 章 · 干预** | 适应轨迹四类（良好适应 66% / 慢性抑郁 13% / 延迟发作 10% / 其他 10–11%）；目标由来访者定；CBT 证据强度 |
| **第 7 章 · 应用伦理** | 未成年人 + 保密例外；转介 |
| **第 9 章 · 污名心理学** | 「看得见的障碍」与「说不出口的伤害」 |
| **第 11 章 · 发展视角** | 青春期身份、同伴关系 |
| **第 12 章 · 家庭与残障** | 照顾者与被照顾者；缺席的父母与在场的阿姨 |
| **第 22 章 · 多发伤** | 多处骨折属于 polytrauma（该章为 9/11 后退伍军人语境，引用需谨慎） |

## 五、三节结构

| 节 | 内容 | 约节点 |
|---|---|---|
| **第一次咨询 · 第一次见面** | 只谈车祸和「什么时候能回去上课」，绝口不提霸凌。被问到「家里谁照顾你」时明显闪避。李阿姨在走廊等他 | 60 → **实际 84** |
| **第二次咨询 · 一周后** | 谈家庭。他在爸妈面前装没事，转头对李阿姨发脾气——**把唯一对他好的人当出气筒**，然后为此自责。真正的戏是：**一个认为「被照顾＝被知道自己很惨」的人，怎么接受照顾** | 55 → **实际 97** |
| **第三次咨询 · 准备回学校** | 他怕的不是「学校还有人打我」，而是「他们都已经知道了」。**危机筛查在这一节触发** | 50 → **实际 74** |
| **终章** | 不是痊愈，也不是回学校 | 5 → **实际 5** |

> 实际 260 节点、53 个选项。比规格的 170 多，是因为每个选择点的三支都写了各自的
> 后果（不是"同一句话换个说法"）。这是刻意的：选项必须真的通向不同的下一句。

### 第 1 节要求

- 开场状态：他坐得很直，双拐靠在沙发边。看起来「很配合」
- 他把所有话题引到**「我什么时候能回去上课」**
- 咨询师第一次问「家里谁照顾你」→ 他答「我妈」→ 再追问 → 改口「……还有个阿姨」
- 不要在这一节就说出霸凌。**玩家不该比他先知道**
- 结束状态：咨询师提出下周再见，他同意得很快——快得像在敷衍

### 第 2 节要求

- 开场状态：他迟到了几分钟，李阿姨在门口跟他说话，他没应
- 主线事件：他对李阿姨发脾气（具体由头留给写台词时定，例如她当着他的面跟咨询师说「他最近晚上老不睡」）
- 关键台词方向：**「她又不是我妈。」**
- 反问：他自己也知道李阿姨对他好——所以发完脾气就自责
- 这一节要让人看见：**他不能接受「我需要别人」，因为那等于承认自己很惨**
- 结束状态：他第一次说出比「挺好的」更具体的一句话

### 第 3 节要求

- 开场状态：学校那边定了复学时间。他反而更退
- 把「怕回学校」的**真实内容**翻出来：不是「还有人打我」，是「他们都已经知道了」
- **危机筛查在这里触发**（见第六节）
- 结束状态：他没有答应回学校，但他答应「下次说说那天放学的事」

## 六、危机分支（写死）

**形式：被动意念，不是主动自杀意念。** 他并不想死，但那一刻「好像不太在乎会不会被撞」。

- 第 3 节由一个 `choice` 引入，咨询师主动筛查
- 「问」→ `effect:'crisis'` 节点 → 走廊空场景 → **写死的资源卡**（`kind:'resource'`）
- 「不问」→ `markScreenMissed` 标记，**无惩罚**
- `check-game.mjs` 强制要求：存在 `effect:'crisis'` 节点，且危机路径必须到资源卡

写作要求：
- 不能写成戏剧化的绝望
- 玩家可见文字里**不出现任何具体方法**
- 咨询师的回应是「关怀 + 求助资源」，不是「分析原因」
- 筛查之后要接得回来——他的反应可以是沉默、可以是「你别告诉我爸妈」

## 七、科普卡与督导笔记

**科普卡 6 张**（2 / 2 / 2 分布三节），每张页脚必须标章节：

| # | 主题 | 依据 |
|---|---|---|
| 1 | 伤后情绪反应不是「心理素质差」 | 第 5 章 |
| 2 | 适应有四条不同轨迹，不只有「好起来」 | 第 5 章 |
| 3 | 看不见的伤与看得见的伤 | 第 9 章 |
| 4 | 为什么「被人知道」比「被欺负」更难受 | 第 11 章 |
| 5 | 照顾你的人，和被照顾的你 | 第 12 章 |
| 6 | 未成年人做咨询，什么情况下不能保密 | 第 7 章 |

**资源卡 3 张**：第 3 节危机分支一张、终章一张、入口常驻一张。

**督导笔记两版一套**：每个 `note` 节点都写两条——`text`（教学版，术语 + 知识点）与
`basic`（新手版，大白话：错在哪、更好的接法是什么）。专家模式两版都不出。
写的时候对着看：同一句话，新手版里不许出现「被动意念 / 保密例外 / 移情 / 阻抗」这类词。

**督导笔记数量**（规格 18 条，实际 56 条：18 / 22 / 16）。密度与 v1 持平（v1 是 74 条 / 3 条线）。
多出来的那些都挂在"这个选择为什么更好/更差"上，节末汇总在一张纸上，可滚动。实现：`say` 节点带 `note:{kind:'supervision'}`，节点的 `text` 就是笔记；游戏内先走聊天气泡，节末由 `collectNotes` 汇总一次。
