## 二、怎么跑起来

### 玩

双击根目录的 **`心理咨询.html`**。就这样。不需要装任何东西，不需要联网。

### 改

源码按职责拆开写，产物是一个文件：

```
src/
  shell.html     页面骨架，含 <!--INJECT:...--> 占位符
  styles.css     全部样式（设计令牌在最上面的 :root）
  sprites.json   15 个像素物件（从方案 B 小样自动抽出，别手改）
  sprites.js     立绘 + 时段变体 + 补充调色板
  story.js       内容数据：故事线一全脚本（改台词只动这个文件）
  engine.js      状态机 + 存档 + 场景渲染
  ui.js          界面：标题页 / 选线 / 对话 / 纸 / 日记 / 逐字写出
build.mjs        合并上面几块 → 心理咨询.html
tools/
  extract-sprites.mjs   从方案 B 抽出像素地图 → src/sprites.json
tests/
  run-all.mjs           一次跑完下面所有检查
```

```powershell
node build.mjs            # 改完源码，重新生成 心理咨询.html
node tests/run-all.mjs    # 全部检查（含开浏览器跑一遍）
```

> **为什么源码不写成单文件**：单文件是**交付**要求，不是**开发**要求。
> 一个 12 万字符的 HTML 里改一句台词，是把整份文档丢给编辑器。

## 三、关键决策记录

> 这一节是存档最要紧的部分——记**做了什么决定、为什么**，避免以后重复讨论。

### 1. 放弃 Phaser 原计划，改为单文件 HTML

| | |
| --- | --- |
| **原计划** | Phaser 4 + TypeScript + Vite + ink + Serverless 后端 + AI 大模型 |
| **决定** | 全部砍掉，改为一个 HTML 文件 |
| **原因** | 原方案需要装 Node、npm install、命令行构建、Serverless 部署、API Key 管理。学生对"游戏引擎"和"剧本量"两处明确表示做不动 |
| **保留** | 咨询室探索、选项式对话、科普内容、危机处理、情绪日记、存档 |

### 2. 不做 AI 自由对话

| | |
| --- | --- |
| **决定** | 全程选项式，玩家不自由打字 |
| **原因** | ① 单 HTML 放不了 API Key；② 危机判断不能交给模型；③ 省掉后端与安全护栏两大块 |

**副作用（好的）**：危机处理"写死在数据里"成了一件天然成立的事，不需要额外论证。

### 3. 美术方案：内联 SVG 像素画

| | |
| --- | --- |
| **决定** | 像素画用**文字字符地图**写进代码，用 SVG `<rect>` 渲染 |
| **对比过的方案** | A 纯 CSS（手写像素太痛苦）、C Canvas 自绘（中文排版和点击都要自己算） |
| **原因** | ① 改画面像打字，不用开画图软件；② 中文排版、按钮点击交给浏览器；③ 真·单文件，没有图片，素材永远不会丢 |
| **验证方式** | A/B/C 三个可双击的对比小样，用户实际打开对比后选定 B |

### 4. 房间改为"正规咨询室"

| | |
| --- | --- |
| **原方案** | 昏暗卧室（心境小屋），放童年物品 |
| **改为** | 符合专业的康复心理咨询室 |
| **依据** | 教育部《中小学心理辅导室建设指南》个体咨询区配置 |
| **具体配置** | 两把浅蓝沙发呈夹角（不面对面）、茶几 + 纸巾盒 + 转介单、挂钟、遮光窗帘、心理挂图、绿植、柔和暖光 |

### 5. 剧情依据改为《康复心理学手册》

| | |
| --- | --- |
| **原剧情** | 原生家庭导致的抑郁症，做 CBT |
| **问题** | 与"康复心理学"课程和该手册的内容**对不上**——手册讲的是人因伤病/残障之后的心理适应 |
| **决定** | 主线改为康复心理学情境；"家庭因素"降级为副线 |
| **已精读章节** | 第 5（干预）、7（伦理）、9（残障社会心理学）、14（慢性疼痛）、16（截肢）、17（脊髓损伤）、18（脑外伤）章 |

### 6. 结构：三条独立故事线，玩家扮咨询师

| | |
| --- | --- |
| **三条线** | 脊髓损伤 / 截肢 / 慢性疼痛 |
| **原因** | 多条线时"玩家扮咨询师"最自然——同一间诊室，不同的来访者；手册第一部分的"核心能力"（评估、干预、伦理）能直接变成玩法 |
| **代价** | 代入感从"被理解"变成"去理解"；写字量约为原计划的 3 倍 |
| **本版取舍** | **先把故事线一做成能双击玩的成品**，再决定另外两条怎么铺。理由见第九节 |

### 7. 保留的功能

| 功能 | 形态 |
| --- | --- |
| **存档** | localStorage，记通关状态 + 当前进度，标题页可"接着上次玩" |
| **情绪日记** | **来访者写的**家庭作业，玩家（咨询师）在第 2 节查看，从中找认知歪曲 |
| **督导笔记** | 每次选完弹一张纸，教学层，**不扣分、不评判玩家** |
| **危机筛查** | 设计成"可以不问"，不惩罚、不扣分，但会留痕，终章提示 |

### 8. 文风定调

| | |
| --- | --- |
| **要求** | **贴近日常，越接近真实情况越好** |
| **执行** | 台词全部口语；咨询师不背金句；来访者会顶嘴（"你这不废话吗"）；去掉对称美的文艺结尾 |
| **虚构要求** | 人物、机构、事件**全部虚构**；但**求助热线必须是真的** |

### 9. 督导笔记 = 全界面唯一的高亮物

| | |
| --- | --- |
| **决定** | 整个界面只有"纸"是亮的（暖黄纸 + 衬线字 + 逐字写出），其余全部压暗 |
| **原因** | 设计上只花一次胆量。房间、对话、按钮都安静，玩家通关后记得住的应该就是这张纸 |
| **附带的一条** | 情绪日记**故意不用纸**——它的来源是手机备忘录。材料的样子要说出来源 |

## 七、专业依据清单

> 全部来自《Handbook of Rehabilitation Psychology》第三版（APA, 2019）

### 脊髓损伤（第 17 章）

- 抑郁发生率约 **22%–28%**（不同样本）
- 心理风险最高的**两个时点**：刚确诊后、**和出院后**
- 抑郁在脊髓损伤人群中**常被漏诊**（被归因于身体问题）
- **>75% 报告疼痛**；疼痛与抑郁共患 **19%–27%**
- 伤后 10 年仍就业者仅 **24%–32%**，截瘫约为四肢瘫两倍，**教育程度是最强预测因子**
- ⚠️ **自杀风险书中只说"高于其他人群"，没有具体数字——不许编**

### 截肢（第 16 章）

- 抑郁症状 **12.9%–32.7%**；焦虑在某些样本达 **29.9%**（普通成人约 12.6%）
- 情绪是 **U 形曲线**：截肢后即刻焦虑/抑郁各 **23.5%** → 住院康复期降到 **2.9%** → 出院后升回 **17.6% / 19.1%**
- **疤痕可见度不预测痛苦程度**；预测因素是伤前对外观的重视程度、抑郁、应对方式
- 幻肢痛**无可靠根治方法**；镜像治疗有一定证据，但可能加重部分人的痛苦
- 美国现存截肢中 **54%** 由外周血管疾病导致，其中约 2/3 合并糖尿病

### 慢性疼痛（第 14 章）

- 定义：持续 **≥6 个月**
- **影像学看不出问题 ≠ 痛是假的**
- **灾难化思维**是预测失能的重要心理因素
- 配偶**过度照顾会强化疼痛行为**；"分散注意"式回应最有利
- CBT 是疼痛领域证据最多的心理干预；正念的目标**不是降低疼痛强度**

### 脑外伤（第 18 章）

- TBI 是**慢性健康状况**，不是一次性事件
- 额叶最易受损，注意、记忆、计划、**自我觉察**问题最典型
- **自我觉察缺失是返工失败的首要原因**，不是"装傻""不配合"
- 严重度分级**不等于预后**

### 干预与伦理（第 5、7、9 章）

- 循证情况：强证据——动机式访谈促身体活动、问题解决训练降照护者抑郁、CBT 治疼痛、协作护理；**中等**——CBT 治 TBI/SCI/MS 抑郁焦虑、自我管理、正念、运动
- CBT 用于脊髓损伤后抑郁：证据等级**中等**（单个 RCT/小样本），**不是"强证据"**
- 适应轨迹：约 **66%** 适应良好 / **13%** 一年内缓解 / **10%** 迟发 / **10%–11%** 持续痛苦
- APA 五原则：行善与不伤害、忠诚与责任、诚信、公正、尊重人的权利与尊严
- 干预目标**必须反映来访者自己定的目标**，不能由专业人员代定
- ⚠️ **"悲伤五阶段"缺乏实证，不许当事实写**

### 开发中踩过、值得记下来的坑

| 坑 | 现象 | 教训 |
| --- | --- | --- |
| 源码注释里写了 `<script` | HTML 解析器当场截断脚本，后面全变成页面文字。**语法检查全绿** | 内联脚本里不能出现标签形态的 script；构建时直接报错 |
| `renderScene` 里 `shadows.forEach(function (s) {...})` 把外层参数 `warmth` 遮住了 | 整间房一个矩形都没画，页面一片黑。静态检查全绿 | 只做 load 的测试没用，**必须真的调一遍渲染** |
| `enter()` 里调了 `saveCurrent()` | 那是挂在下面对象字面量上的函数表达式，此时还没赋值 → ReferenceError。走到危机分支就卡死 | 函数声明会提升，函数表达式不会；加一条状态机真跑一遍的测试 |
| `sprites.js` 加载时读调色板，但数据是启动脚本才注入的 | 启动即崩 | 数据要在第一段脚本里就抓进来，别等到 boot |
| PowerShell 的 `Set-Content` 往返改文件 | 中文全被替换成 `?`，两个测试脚本报废 | **不要用 shell 重写 UTF-8 源码**；用编辑工具 |
