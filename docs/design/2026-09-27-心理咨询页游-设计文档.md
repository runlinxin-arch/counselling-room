## 一、这是什么

一个**叙事驱动 + 选项对话**的康复心理学科普游戏。玩家扮演康复医院心理门诊的咨询师，
接待一位脊髓损伤后来访的年轻人，走完三次小节。

- 玩法：读对话 → 做选择 → 点房间里的东西拿科普 → 写不出字，全程只用鼠标
- 目标：让玩家**体验到**"目标调整"长什么样，而不是被讲一遍
- 玩家不需要任何心理学背景；但玩完之后应该记住两三件事（抑郁常被漏诊、目标得来访者自己定、CBT 只是中等证据）

## 二、视觉方向

**一句话**：一间下午三点的咨询室。外面很亮，里面拉着遮光窗帘。

这不是"暗色主题"，是**拉上窗帘的房间**。所以画面整体压暗、偏冷灰，
只有三个东西是暖的：落地灯的暖光、督导笔记的纸、来访者手里那杯水。
玩家在屏幕上就是坐在这个房间里——**整个屏幕是咨询室，不是"一个房间加一个对话框"**。

### 字体

| 用途 | 字体 | 为什么 |
|---|---|---|
| 界面 / 对话 | `"Noto Sans SC","Microsoft YaHei",system-ui,sans-serif` | 屏幕上读小字，无衬线最稳；系统自带，不下载、不依赖网络 |
| **督导笔记** | `"Noto Serif SC","Source Han Serif SC","Songti SC",serif` | 笔记是**写在纸上的**东西。换个字体，它就从"系统提示"变成"一份材料" |
| 数字 / 计时 | `ui-monospace,Consolas,monospace` | 数字对齐；也用在小节编号上 |

**不加粗体做强调**——中文加粗难看。强调靠颜色（暖灯黄、沙发蓝）和换行。

```
├────────────────────────────────────────────────────┤

│                                                    │
├────────────────────────────────────────────────────┤

│  你好，我是这儿的心理咨询师。今天大概五十分钟，        │  ← 对话（最大字号）
│  你看行吗？                                         │
│                                                    │
│  ┌──────────────────────────────────────────────┐  │
│  │ 1  今天想先认识一下你。你想聊啥，咱就聊啥。      │  │  ← 选项：编号是键盘快捷键，不是装饰

└────────────────────────────────────────────────────┘
```

- 房间 636×360 是**固定像素网格**（106×60 逻辑像素 × 6），不许缩放成 1.5 倍之类的非整数倍，会糊
- 视口矮的时候，整块 `#screen` 一起等比缩小；房间自己不变形
- 选项编号 `1/2/3` 是真的能按：键盘 `1` `2` `3`，兼顾"只用鼠标"

### 唯一的记性点（signature）

**督导笔记**。每次选择后，一张纸从右边滑进来，文字**一个字一个字划出来**（不是打字机，
是"写"的节奏——按标点停顿）。纸是暖黄的，字体是衬线，右上角写着"督导笔记"。

它同时干三件事：教学反馈、视觉上唯一的高亮物、以及"你被督导看着"这件事本身。
玩家通关后应该记得这张纸——**别的都可以忘，这张纸不能**。

配套的一条：**转介单**。它躺在茶几上，用箭头标出用处——"别人对他的判断"。
这张纸上写的是别人说的话，不是他本人说的话；它一开始就摆在最显眼的地方。

> 减掉的一个配件：原本想做"情绪日记"也用手写体纸片。三个手写体就吵了。
> 日记改成**手机备忘录的样子**（无衬线、灰、行距松），因为它的来源本来就是手机。
> 材料的样子要说出来源。

### 动效（只留三处，别的一律不动）

1. 督导笔记：纸从右滑入 + 文字逐字写出（约 0.9 秒）
2. 暖光：房间上那层径向暖光，明暗随剧情走（开局最暗，终章最亮）
3. 转场：小节之间房间淡出淡入一次

房间里的箭头标注是**静态的**：出现、读到、随台词往下走时收起。它不呼吸、
不闪烁——像素画本身已经够密，再叠动效就只剩吵。

`prefers-reduced-motion: reduce` 时全部关闭，逐字写出改成直接显示。

### 文案调子

台词全部口语，**咨询师不背金句**。来访者可以顶嘴（"你这不废话吗"）。
界面文字用"你"，不用"您"，不用感叹号。按钮说清楚按下去会发生什么（"知道了" / "继续" / "回标题"）。

## 三、页面流程

```
标题页
 ├─ 虚构声明 + 免责声明 + 热线（1/3 处）
 └─ [开始] → 选线页（2/3 处入口：页头常驻"我很难受"按钮）

选线页
 ├─ 一 · 脊髓损伤      林越 26 岁 T6 完全性 伤后 14 个月   ✅ 可玩
 ├─ 二 · 截肢          —— 剪影 · 即将推出                🔒
 └─ 三 · 慢性疼痛      —— 剪影 · 即将推出                🔒
      存档能读出"已完成"，完成后卡片上多一个「✓ 已完成」

第 1 节 · 第一次见面
 1. 旁白开场（他早到十分钟）
 2. 【选项 1】开场白  A 复述转介单 / B 你想聊啥就聊啥 / C 最近怎么样
 3. 说明设置（保密 + 保密例外 + 可以拒答）——**必走，不能跳**
 4. 【选项 2】"听明白了吗" / "哪条想再问细点" / 直接往下
 5. 房间箭头标注：墙上的钟、茶几上的纸巾盒、两把沙发、转介单，直接标出各自的用处
 6. 【伦理抉择】走廊碰见王医生  A 答应 / B 我先看他想干啥 / C 站不起来
 7. 【危机筛查】问 / 不问
     问 → 危机关怀分支 → 资源卡（2/3 处）+ 存档留痕
     不问 → 可以，不扣分，存档标记"未完成"，终章提示
 8. 留作业：记一下每天啥时候最难受 → 解锁情绪日记

第 2 节 · 一周后
 1. 情绪日记面板（手机备忘录样式）：周一 / 周三 / 周五 / 周日
 2. 【选项 5】先谈哪一条（四条都能谈，内容不同）
 3. 谈完后 → 科普卡 3（自动化思维 + CBT 证据等级只是中等）
 4. 结尾：下回那个念头冒出来，你看它一眼

第 3 节 · "等我能走了"
 1. 林越抛出全场最关键的一句
 2. 【选项 6】A 你得接受现实 / B 我听到的是你在等 / C 也许生活不是这个顺序
 3. 把大目标拆成今天能做的事（老张婚礼 → 酒店有没有坡道）
 4. → 科普卡 4（"悲伤五阶段"缺乏实证 + 真实适应轨迹）
 5. 结尾：这周，你会不会去问一下那个坡道

终章
 1. 旁白："我下周还来。"
 2. 成绩单：这一节做成了什么 / 危机筛查状态 / 看过的科普卡
 3. 资源卡（3/3 处）+ 虚构声明（再次出现）
 4. [回标题页] → 存档标记"故事线一 已完成"
```

### 三个可选的功能性设计

| 功能 | 形态 | 为什么不砍 |
|---|---|---|
| **督导笔记** | 选完弹一张纸，逐字写出 | 这是课程作业的教学层，砍了就只剩故事 |
| **情绪日记** | 玩家逐条点开四条备忘录 | 让玩家**自己**从上头找出认知歪曲，比被告知有用 |
| **危机筛查可以不问** | 真选项，不惩罚 | 只有"不问"是真的选项，玩家才会真的想"我该不该问" |

## 四、数据格式

引擎只认识下面这几种节点。它**不认识"脊髓损伤"**——换一条线只是换一份数据。

```js
// 一条故事线 = 一个对象
{
  id: 'sci',                    // 存档用的稳定 id，别改
  title: '脊髓损伤',
  subtitle: '一 · 把「等我能走了」当成人生的前提',
  client: { name: '林越', age: 26, detail: 'T6 完全性脊髓损伤 · 伤后 14 个月' },
  sections: [ { id: 's1', title: '第 1 节 · 第一次见面', nodes: {...} }, ... ],
  start: 's1/open',
  ending: 'ending'
}
```

### 节点

```js
's1/open': {
  // 说一句话。一次一句，玩家按一下走一句。
  type: 'say',
  who: '旁白' | '咨询师' | '林越' | '王医生',   // 决定说话人颜色；省略 = 旁白（斜体灰）
  text: '他比约定时间早到了十分钟。',
  act: 1,                     // 可选：切换房间时段（钟针位置、有没有轮椅）
  effect: 'unlockDiary',      // 可选：改状态。见下表
  allowItems: ['clock','tissue'],   // 可选：这一段允许点房间里的东西
  note: {                     // 可选：一张纸
    kind: 'supervision' | 'science' | 'referral' | 'resource' | 'result',
    title: '督导笔记',
    body: '一段话。\n\n换行用 \\n。',
  },
  next: 's1/open2',           // 下一句
}

// 让玩家选。所有选项都有 next，**没有死路**。
's1/choice1': {
  type: 'choice',
  prompt: '开场',
  options: [
    { key: 'A', label: '王医生说你这段时间训练不太配合，咱先聊聊这个。', next: 's1/a', flag: 'openA' },
    ...
  ],
}

// 弹出情绪日记面板
's2/diary': { type: 'diary', entries: [ { id:'mon', day:'周一', lines:[...] } ], next: 's2/choice5' }

// 弹资源卡（危机关怀用）
's1/crisisCard': { type: 'card', kind:'resource', title:'...', body:'...', next: '...' }

// 结束
'ending': { type: 'end' }
```

### 状态字段（存档里会存下来的）

| 字段 | 含义 |
|---|---|
| `line` | 当前节点 id |
| `flags{}` | `openB` / `screened` / `crisisTriggered` / `diaryRead[]` / `cardsRead[]` / `itemsClicked[]` |
| `choices[]` | 按顺序记的 `{node, key}`，终章复盘和报告都能用 |
| `warmth` | 0–3，房间暖光明暗（每节 +1） |

## 五、存档结构

浏览器 `localStorage`，用一个 key，**JSON 里带版本号**，以后改结构能迁移：

```js
// key: 'xlzx.save.v1'
{
  v: 1,
  done: { sci: true, amp: false, pain: false },   // 故事线通关状态（跨局保留）
  current: {                                       // 当前进度（可选，回标题后保留）
    line: 'sci/s2/choice5',
    flags: { openB: true, screened: true, crisisTriggered: false, diaryRead: ['mon','wed'] },
    choices: [ { node:'sci/s1/choice1', key:'B' } ],
    warmth: 2
  },
  lastPlayed: 1758970000000
}
```

- **没有服务器**，存档只在本地；清浏览器数据就没了（标题页有一行小字说明）
- `done` 和 `current` 分开：通关一条线，不该把另外两条的解锁状态冲掉
- 存档写坏的容错：`JSON.parse` 失败就当作没有存档，不要白屏

## 七、自查：红线逐条落点

出自 `docs/项目存档-Notion.md` 第七节。**开发时逐条核，做完再核一遍。**

| 红线 | 在哪儿落地 |
|---|---|
| 咨询师不下诊断、不给药物建议、不评判来访者家人 | 全部台词写在 `src/story.js`，终章做一遍全文搜（"诊断""吃药""你妈就是"） |
| 危机处理写死在代码里，不经过任何模型判断 | 本作无模型、无后端。危机节点是普通数据节点，`type:'card'` + `effect` 推进 |
| 免责声明 + 热线 ≥3 处 | ① 标题页；② 页头常驻「我很难受」按钮（每屏都能点）；③ 终章资源卡 |
| 热线号码正确 | `12356` 全国 / `010-82951332` 北京 / 立即危险 `120`；自检脚本搜这三个 |
| 术语规范：抑郁症 / 抑郁障碍 | 全稿搜"抑郁病""精神病"应为 0 |
| person-first："脊髓损伤的人" | 全稿搜"瘫子""残疾人""病人"应为 0 |
| 避免"恢复正常"叙事 | 全稿搜"恢复正常""重新站起来"应为 0 |
| 不把困难归因于个人性格、忽略环境障碍 | 台词里"是因为这场事故。不是因为你。"；科普卡 2 讲台阶与扶手 |
| 所有选项都能继续 | 自检脚本检查每个 `options[].next` 都存在 |
| 人物、机构、事件全部虚构 | 正文只有"康复医院""门诊""物流公司"；终章再出现一次虚构声明 |
| 每个数字有出处，没有的绝不编 | 见下表；自检脚本对一个白名单，出现不在表里的数字就报警 |
