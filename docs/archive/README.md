# 归档区

这里存放**已作废**的文档。原件不做任何修改——归档只做索引，不改内容，所以打开这些文件时你仍会读到与现状矛盾的方案，那是历史原貌，不是笔误。

## 为什么归档而不是删除

因为「为什么放弃某个方案」比方案本身更有价值，它是判断力的证据。但留着不管，则会继续误导执行者（包括 AI agent）——这个仓库已经因为过时文档差点走错一次。
