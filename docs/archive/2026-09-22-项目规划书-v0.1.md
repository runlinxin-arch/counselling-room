# 《心理咨询》网页游戏 · 项目规划书

> 版本：v0.1（2026-09-22）
> 用途：康复心理学学期大作业（13 周），同时为日后完整版（Steam）奠基

---

## 一、项目定位

- **第一目标**：课程作业，达到「科普心理咨询与心理障碍」的水平
- **长期愿景**：毕业后扩展为完整的沉浸式游戏，上线 Steam（届时迁移 Unity）
- **类型**：叙事驱动 + AI 对话的心理咨询模拟游戏
- **玩家角色**：扮演一位因原生家庭问题罹患抑郁症的来访者，与 AI 咨询师对话，一步步探索内心世界

## 二、核心设计决策（已确认）

| 维度 | 决策 |
|---|---|
| 题材 | 原生家庭问题导致的**抑郁症**（报告统一用「抑郁症/抑郁障碍」规范术语） |
| 对话实现 | **混合式**：剧本主线锁轨道 + AI 自由对话做温度 |
| 课程版咨询师 | **仅 CBT 一条完整线**；人本 / 精神动力两位咨询师在选人界面显示为「即将推出」剪影 |
| 主角 | **预设角色**（固定形象与家庭背景设定） |
| AI 自由对话 | **保留但收窄**：全游戏仅 2~3 个精心设计的环节开放自由输入（如初诊"说说你最近的感受"） |
| 内心世界呈现 | **可行走的心境小屋**（方案 A+C）：玩家操控角色在房间内探索，随剧情解锁更多可交互物品与场景 |
| 美术风格 | 卡通手绘风（AI 生成素材） |
| 技术栈 | **网页技术（Phaser 2D 引擎）**，毕业后再考虑 Unity 迁移 |
| 交付形式 | 网页游戏（浏览器直接打开/访问） |

## 三、游戏结构（5 章）

以心理咨询真实流程为骨架：

1. **第 0 章 · 初诊**：见咨询师，建立信任；科普咨询设置（保密原则等）。**首个自由输入环节**。
2. **第 1 章 · 表面问题**：当下困扰（情绪低落、失眠、没动力）；识别自动化思维。科普：抑郁症状与认知模型。
3. **第 2 章 · 往下挖掘**（合并章，体量最大）：触达核心信念（"我不值得被爱"）；心境小屋解锁"童年记忆区"，点击物品触发记忆片段，回到咨询室讨论。科普：核心信念与早期经历、依恋模式。
4. **第 3 章 · 重构与行动**：认知重构 + 行为激活（情绪日记等"家庭作业"），允许反复。科普：行为激活、复发与应对。
5. **终章 · 告别**：不是"痊愈"而是"带着工具继续生活"；片尾放心理援助资源。

**心境小屋**：内心具象化为一个房间。开局昏暗、窗被灰尘糊住、一扇门上锁；每章咨询后房间变亮一点；第 2 章解锁门后"童年记忆区"（成绩单、摔碎的杯子、小了的旧衣服等物品 → 记忆片段）。

## 四、CBT 咨询师人设（草案，待细化）

- 流派：认知行为取向为主，人本主义为底色
- 说话方式：结构化、温和、会布置小作业、帮玩家识别扭曲思维
- 有具体人物形象与办公室细节（待与美术一起定稿）

## 五、AI 对话安全边界（已确认）

- AI 只做**共情回应与开放式提问**（"听起来你当时很孤单，能多说说吗"）
- **永远不**：主动给诊断、给药物建议、评判玩家的家人
- 玩家输入触及自伤/自杀信号 → **立即切换剧本写死的"关怀 + 求助资源"回应**
- 游戏内必须包含：免责声明（"本游戏不能替代真实心理咨询"）+ 心理援助热线信息

## 六、技术架构（初定）

- 前端：Phaser 3（场景：咨询室对话 UI + 心境小屋探索）
- AI 链路：前端 → 轻量后端中转（保护 API Key）→ 大模型 API
- 部署：静态托管（课程版）；后端可用 Serverless 函数
- 版本管理：Git，每次大改前存档

## 七、13 周路线（初排）

| 周 | 目标 |
|---|---|
| 1–2 | 学习"驾驶员技能"（读得懂 HTML/JS、跑本地预览、F12 看报错、Git 存档）；搭项目骨架 |
| 3–4 | 垂直切片：咨询室对话系统跑通（剧本数据格式 + 选项 UI） |
| 5–6 | 心境小屋：角色行走 + 物品交互 + 场景明暗变化 |
| 7–8 | AI 自由对话环节：后端中转 + 系统提示词 + 安全护栏 |
| 9–10 | 剧本写作：5 章完整剧本 + 记忆片段（最大工作量，与程序穿插进行） |
| 11 | 美术素材生成与整合（卡通手绘风） |
| 12 | 测试、修 bug、免责声明与求助资源页 |
| 13 | 打磨、录演示、写课程报告 |
